# ED1 — TAD Lista — LinkedList

Implementação de uma **Lista Dinâmica Encadeada (LinkedList)** utilizando C++ e conceitos de **Tipo Abstrato de Dados (TAD)**.

O projeto apresenta uma separação entre:

- **Interface abstrata:** define o contrato genérico da lista.
- **Implementação:** utiliza alocação dinâmica de nós encadeados em memória utilizando ponteiros.
- **Testes:** validam as principais operações disponibilizadas pela lista, verificando estados e liberação de memória.
